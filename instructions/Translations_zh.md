# Translations

Czkawka/Krokiet 支持大约 20 种语言。主要（默认）语言是英语，波兰语也得到了官方支持。

该应用程序使用简单的 Fluent 本地化系统：https://projectfluent.org/

大部分翻译在 Crowdin 上管理：https://crowdin.com/project/czkawka

如果你想将 Czkawka 翻译成你的语言，可以在该平台上进行。

随着每个新版本的发布，会添加或修改许多字符串。因为大多数语言缺乏专门的翻译人员，部分翻译是使用 Crowdin 的机器翻译系统或本地 LLM 模型生成的。这些翻译可能不完美，仍然需要人工审核，但它们大大减少了人工翻译者所需的工作量。
