## 术语表

关于共享术语（参考路径、包含/排除路径、排除项目、缓存）请参见 [主指南中的术语表](Instruction.md#terminology-shared-across-all-frontends)。

Krokiet 特定或工具聚焦术语：

| 术语 | 定义 |
|------|------|
| **感知哈希** | 从视觉或音频内容计算的哈希值，设计为相似内容产生相似哈希值。用于相似图像、视频和音乐指纹模式。 |
| **预哈希** | 对文件开头和结尾计算的快速部分哈希。用于在计算完整哈希之前快速排除非重复项，加速大型扫描。 |
| **哈希组** | 共享相同哈希值（或在选定阈值内视觉相似）的一组文件 - 候选重复项。 |
| **相似度阈值** | 对于相似图像/视频/音乐：两个项目被视为相似所允许的最大差异。越低越严格。 |
| **预设** | 保存的配置文件，存储扫描目录、过滤器和工具参数。可以创建并切换多个预设。 |
| **后端/渲染器** | 用于绘制 Krokiet 窗口的图形 API。选项：femtovg（OpenGL，默认）、skia、software。在异常设置或 OpenGL 不可用时使用 `software`。 |
| **硬链接** | 文件系统功能，两个文件名指向同一 inode。Krokiet 检测硬链接并默认仅计算一次，以避免误报重复项。 |

## 安装

预构建的二进制文件（无需额外依赖）适用于 Windows 10/11、macOS 和 Ubuntu 22.04+。

从 [GitHub 发布页面](https://github.com/qarmin/czkawka/releases) 下载。

对于 **相似视频** 工具，必须单独安装 **ffmpeg**：

| OS | 命令 |
|----|------|
| Linux | `sudo apt install ffmpeg` |
| macOS | `brew install ffmpeg` |
| Windows | `choco install ffmpeg` 或从 ffmpeg.org 下载并将 `ffmpeg.exe` 放在 `PATH` 中 |

### 可选功能（仅限源码编译）

| 功能 | 库 | 用途 |
|---------|---------|---------|
| `heif` | `libheif` | HEIF/HEIC 图像支持 |
| `libraw` | `libraw` | RAW 相机图像支持 |
| `libavif` | `libavif`, `libdav1d` | AVIF 图像支持 |

### 从源码编译

```shell
# 最简单 - 安装最新的优化二进制文件
cargo install krokiet --locked

# 带可选图像格式支持
cargo build --release --bin krokiet --features "heif,libraw,libavif"
```

### 备选渲染器

默认构建 femtovg（OpenGL）和软件渲染器。在运行时切换：

```shell
SLINT_BACKEND=software ./krokiet        # 纯软件渲染，最安全的回退
SLINT_BACKEND=winit-femtovg ./krokiet  # 通过 femtovg 的 OpenGL（默认）
SLINT_BACKEND=skia ./krokiet           # Skia（需要 winit_skia_opengl 编译功能）
```

要验证哪个后端处于活动状态：

```shell
SLINT_DEBUG_PERFORMANCE=refresh_lazy,console,overlay ./krokiet
# 打印："Slint: Build config: release; Backend: femtovg"
```

### 左侧面板 - 工具列表

可用工具：重复文件、空文件夹、大文件、空文件、临时文件、相似图像、相似视频、同类音乐、无效符号链接、损坏文件、错误扩展名、错误名称、Exif 移除器、视频优化器。

### 目录面板

由操作栏右侧的文件夹图标按钮切换。仅包含：

- **包含路径** - 将要扫描的目录。每行都有一个 "Ref" 复选框，用于将其标记为参考路径（受删除保护）。使用顶部的文件夹/文件/手动输入按钮添加路径。
- **排除路径** - 扫描期间将被忽略的目录。使用相同的按钮添加。

扩展名、大小过滤器、排除项目和递归搜索在 **设置** 中配置，不在此处。

### 结果区域

- **标题行**（加粗）表示组（例如重复文件组或一组相似图像）。
- **文件行** 显示名称、路径、大小和工具特定的额外信息（例如图像尺寸、相似度分数）。
- 左键单击行切换其选择（也会反转预览焦点）。Ctrl+click 反转单个选择而不改变其他；Shift+click 选择一个范围。
- 双击左键在默认应用程序中打开文件。
- 右键单击打开上下文菜单：打开项目、打开父文件夹、从结果中移除、从文件夹移除全部、从文件夹移除全部（递归）、从文件夹选择全部、从文件夹选择全部（递归）、排除父文件夹、排除项目、复制文件名、复制父文件夹、复制完整路径、重命名。

### 操作栏

操作栏位于结果区域下方。根据活动工具和是否存在结果，可见的按钮有所不同。

**始终存在（非扫描时）：**
- **Scan** - 开始活动工具的扫描
- **Select** - 打开带有选择预设的弹出窗口：全部选择、全部取消选择、按大小或分辨率的最旧/最新/最大/最小，除最旧/最新/最大/最小（按大小或分辨率）之外全部选择，选择最短/最长路径，反转选择，反转组内选择，自定义（按列值筛选）
- **Move** - 将选定文件移动到所选目录
- **Delete** - 永久删除选定文件
- **Trash** - 将选定文件移动到系统垃圾桶（可恢复）
- **Save** - 将结果导出到文件
- **Sort** - 打开排序选项弹出窗口

**工具特定按钮（仅对相关工具显示）：**
- **Rename** - 应用文件名建议修复（错误扩展名和错误名称）
- **Optimize** - 转码/裁剪选定的视频（视频优化器）
- **Clean** - 从选定文件中删除 EXIF 元数据（Exif 移除器）
- **Compare** - 打开并排图像比较叠加层（相似图像，当存在结果时）
- **Hardlink** / **Softlink** - 将重复项替换为硬链接或符号链接（返回分组结果的工具）

## 逐工具指南

### 重复文件

查找内容相同（或名称/大小匹配，取决于所选方法）的文件。

**子设置（右侧窗格）：**

检查方法（UI 顺序，Hash 为默认）：

| 方法 | 说明 |
|------|------|
| Hash | 通过哈希值比较完整文件内容；推荐；默认 |
| Size | 仅比较文件大小；许多误报 |
| Name | 仅比较文件名；许多误报 |
| Size and Name | 结合大小和名称比较 |

哈希类型（与 Hash 方法一起使用）：

| 哈希 | 说明 |
|------|------|
| Blake3 | 默认 |
| CRC32 | |
| XXH3 | |

区分大小写 - 仅用于基于名称的方法。

**在全局设置（在 "重复文件" 部分下）：**
- 图像预览 - 为选定的重复项显示缩略图
- 缓存文件的最小大小 - Hash (KB) - 缓存哈希值的最小文件大小
- 使用预哈希 - 缓存部分哈希（开头/结尾字节）以更快地跳过非重复项
- 缓存文件的最小大小 - Prehash (KB)

### 空文件夹

查找不包含文件或子目录的目录。使用递归算法，将 "非空" 状态向上传播到目录树。没有子设置。

### 大文件

查找指定目录中 N 个最大（或 N 个最小）文件。

**子设置（右侧窗格）：**
- 方法：最大 / 最小
- 文件数量（默认 50）

### 空文件

查找 0 字节的文件。

**子设置（右侧窗格）- 要查找的其他文件类型：**
- **全为空字节的文件** - 还查找非空且整个内容为空字节 (0x00) 的文件；默认禁用
- **全为不可打印字符的文件** - 还查找仅包含不可打印 ASCII 字符（空字符、空格、制表符、CR、LF、VT、FF）的文件；默认禁用

### 临时文件

查找匹配常见临时文件模式的文件。

**子设置（右侧窗格）：**
可编辑的扩展名/模式列表，带重置按钮。默认列表：
`#,thumbs.db,.bak,~,.tmp,.temp,.ds_store,.crdownload,.part,.cache,.dmp,.download,.partial`

### 相似图像

查找看起来相似但并非逐字节相同的图像（不同分辨率、水印、压缩伪影、JPEG 重新保存等）。

**子设置（右侧窗格）：**

| 设置 | 默认值 | 说明 |
|---------|---------|-------|
| 哈希大小 | 16 | 选项：8, 16, 32, 64。越大越精确；需要更高的最大差异阈值。 |
| 调整大小算法 | Lanczos3 | 选项：Lanczos3, Nearest, Triangle, Gaussian, CatmullRom。 |
| 哈希类型 | Mean | 选项：Mean, Gradient, BlockHash, VertGradient, DoubleGradient, Median。BlockHash 在哈希前不调整大小。 |
| 几何不变性 | Off | 选项：Off, Mirror + Flip, Mirror + Flip + Rotate 90。 |
| 忽略相同大小的图像 | off | 跳过所有图像字节大小相同的组。 |
| 忽略相同分辨率的图像 | off | 跳过所有图像像素尺寸相同的组。 |
| 最大差异 | 10 | 最大哈希距离。提高以获得更多匹配，降低以更严格。 |

**在全局设置（在 "相似图像工具" 部分下）：**
- 图像预览 - 为选定的图像显示缩略图

### 相似视频

查找视觉或声学相似的视频。需要 **ffmpeg** 已安装。

**子设置（右侧窗格）：**

顶部切换：**按音频指纹比较** - 在视觉和音频比较模式之间切换。

**视觉模式**（默认）：
- 快速预设：自定义 / 近乎相同 / 相似 / 电影（长跳过）。非自定义预设会自动设置下面的滑块。
- 当自定义时：最大差异 (0-20，默认 15)，跳过时长 [s]，视频哈希时长，窗口计数（默认 5），持续时间容差 [%]（默认 20），最小匹配窗口（默认 60%），子片段最小匹配
- 信箱裁剪检测（仅自定义）
- 忽略相同大小的视频
- 忽略相同分辨率的视频

**音频指纹模式：**
- 快速预设：自定义 / 相同视频 / 较长视频中的片段 / 相似内容
- 当自定义时：相似度 [%]，最小长度比（较短/较长），最小文件时长 [s]，最大音频差异
- 忽略相同大小的视频
- 忽略相同分辨率的视频

**在全局设置（在 "相似视频工具" 和 "视频缩略图" 部分下）：**
- 生成缩略图 - 为结果预览启用缩略图生成
- 视频中的缩略图位置 (%)
- 生成缩略图网格而非单张图像
- 缩略图网格每边的瓦片数
- 应用启动时删除 7 天前的未使用视频缩略图

### 同类音乐

查找重复或相似的音乐文件。

**子设置（右侧窗格）：**

音频检查类型：**标签**（默认）或 **指纹**。

当为标签时：
- 近似标签比较切换
- 单独可切换的比较标签：标题（开启）、艺术家（开启）、比特率（关闭）、流派（关闭）、年份（关闭）、长度（关闭）

当为指纹时：
- 在相似标题组内比较切换
- 最大差异滑块
- 最小片段时长滑块

### 无效符号链接

查找目标不存在或形成循环链的符号链接。没有子设置。

### 损坏文件

查找无法使用其预期库打开的文件（内容损坏或截断）。

**子设置（右侧窗格）- 要检查的文件类型（默认值如下）：**
- 音频 - 默认开启
- PDF - 默认关闭
- 存档 - 默认关闭
- 图像 - 默认关闭
- 视频 (ffprobe) - 默认关闭；快速头部检查，需要 ffmpeg
- 视频 (ffmpeg) - 默认关闭；完整解码，非常慢，需要 ffmpeg
- 字体 - 默认开启
- 标记 (JSON/XML/TOML) - 默认开启

注意：根据所使用的库，可能会出现误报。删除前请务必验证。

### 错误扩展名

查找内容（通过魔数字节检测）与扩展名不匹配的文件。没有子设置。

"正确扩展名"列显示检测到的类型和兼容扩展名。使用 **重命名** 按钮应用建议的修复。

### 错误名称

查找名称有问题的文件。

**子设置（右侧窗格）- 检查（默认值如下）：**
- 大写扩展名（例如 `.JPG`） - 默认开启
- 名称中的表情符号 - 默认开启
- 开头/结尾空格 - 默认开启
- 非 ASCII 字符（例如 ą, ć, ñ） - 默认开启；建议 ASCII 等效项
- 受限字符集 - 默认关闭；转写为 ASCII 然后标记 0-9a-zA-Z 之外加上用户定义的允许字符；启用后，会出现 "允许字符" 文本字段（默认 `_- `）
- 重复字符（例如 `file---name`） - 默认关闭；标记连续重复的非字母数字字符

结果包含建议的修正名称。

### Exif 移除器

查找包含 EXIF 元数据（GPS 坐标、相机型号、创建日期等）的图像文件。

**子设置（右侧窗格）：**
- 忽略的标签 - 要保留的 EXIF 标签名称的逗号分隔列表（留空以剥离所有标签）

使用 **Clean** 按钮从选定文件中删除 EXIF。

### 视频优化器

识别适合优化的视频。

**子设置（右侧窗格）：**

模式：**裁剪**（默认）或 **转码**。

当为裁剪时：
- 裁剪类型：黑边（默认）/ 静态内容
- 黑色像素阈值
- 黑边最小百分比

当为转码时：
- 排除的编解码器 - 要跳过的编解码器（默认：`h265,av1,vp9`；可用重置按钮）

使用 **Optimize** 按钮处理选定的视频（打开带输出设置的确认弹出窗口）。

## 设置

通过左侧面板底部的齿轮图标打开设置。设置是一个带节标题的单个滚动列表 - 不是选项卡视图。

**扫描过滤器**（这些在这里，而不是在目录面板中）：
- **允许的扩展名** - 留空以扫描所有类型，或输入逗号分隔的值（例如 `jpg,png`）。支持关键字：`image`、`video`、`text`（扩展到相关扩展名列表）。
- **排除的扩展名** - 要跳过的扩展名
- **排除的项目** - 过滤掉的 glob 模式（例如 `*/tmp*`、`*/.git`）
- **文件大小 (KB)** - 最小和最大文件大小过滤器
- **递归搜索** - 切换是否扫描子目录

**常规：**
- **语言** - UI 语言；更改立即生效，无需重启
- **深色主题** - 切换深色/浅色主题；立即生效
- **仅显示图标** - 隐藏操作栏中的按钮标签
- **隐藏硬链接** - 在结果中仅计算一次硬链接文件

**性能：**
- **线程数** - 要使用的 CPU 线程；需要重启才能生效
- **使用缓存** - 启用/禁用哈希和缩略图缓存
- **使用预哈希**（重复文件部分） - 缓存大文件的部分哈希以加速重新扫描
- **自动删除过时的缓存条目** - 自动清理过时的缓存记录（最多每周验证一次）
- **应用缩放** - 手动 UI 缩放因子；需要重启才能生效

### 预设

每个预设存储：包含/排除路径、扩展名和大小过滤器、工具特定参数。

预设保存在 `~/.config/krokiet/config_preset_N.json`（Linux）。

## 常见工作流

### 在保护备份的同时删除重复项

1. 将你的工作文件夹添加到 **包含路径**
2. 将你的备份文件夹添加到 **包含路径**
3. 在备份文件夹行中勾选 **Ref** 复选框
4. 选择 **重复文件** 工具，设置方法 **Hash**，哈希类型 **Blake3**
5. 点击 **Scan**
6. 点击 **Select** → 选择 "除最新" 或其他适合的策略
7. 验证没有参考路径文件被选中
8. 点击 **Trash** 或 **Delete**

### 清理照片库（相似图像）

1. 将所有照片目录添加到 **包含路径**
2. 选择 **相似图像** 工具
3. 设置相似度 **10**，哈希大小 **16**，算法 **Mean**（默认）或 **Gradient**
4. 启用 **几何不变性** 如果你想捕获镜像/旋转的副本
5. 点击 **Scan**
6. 使用右侧预览窗格在决定前视觉对比配对
7. 手动选择每个组中要保留的图像，删除其余图像

### 通过 CLI 预扫描视频缩略图，加快 GUI 加载

```shell
czkawka_cli video -d /your/videos --generate-thumbnails
```

这会填充缩略图缓存，以便 Krokiet 下次打开时无需重新计算即可显示预览。

## 配置和缓存文件

有关默认路径、缓存文件描述、环境变量覆盖和便携式驱动器设置，请参见 [主指南中的配置/缓存文件](Instruction.md#configcache-files)。

### Krokiet 配置文件

| OS | 路径 |
|----|------|
| Linux | `~/.config/krokiet/` |
| macOS | `~/Library/Application Support/pl.Qarmin.Krokiet/` |
| Windows | `C:\Users\<user>\AppData\Roaming\Qarmin\Krokiet\config\` |

注意：不存在 Krokiet Flatpak。Flathub 包仅适用于 GTK，且已冻结在 v10.0。

关键文件：
- `config_general.json` - 窗口大小、主题、预设数量、活动预设索引
- `config_preset_N.json` - 预设 N 的所有扫描设置（路径、过滤器、工具参数）
- `config_custom_select_state.json` - 已保存的自定义选择规则

缓存与 GTK 和 CLI 共享（Linux 上为 `~/.cache/czkawka/`）。
