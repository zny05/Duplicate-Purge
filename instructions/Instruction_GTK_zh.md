# Czkawka GTK - 说明

> **弃用通知**：Czkawka GTK 12.0 是最后一个发布的版本。不会再提供新的二进制文件。新用户和现有用户都鼓励迁移到 [Krokiet](Instruction_Krokiet.md)。

## GUI 概览

<img src="https://user-images.githubusercontent.com/41945903/148281103-13c00d08-7881-43e8-b6e3-5178473bce85.png" alt="Czkawka GTK main window" width="800" />

GUI 由不同部分组成：
- **1** - 图像预览 - 用于重复文件和相似图像查找器。无法调整大小，但可以禁用。
- **2** - 主要笔记本，用于更改活动工具。
- **3** - 主要结果窗口 - 允许选择、删除和配置结果。
- **4** - 底部面板 - 包含对数据执行特定操作的按钮（如选择数据）或隐藏/显示 GUI 部分。
- **5** - 文本面板 - 打印执行操作的消息、警告和错误。可以由用户隐藏。
- **6** - 目录面板 - 用于选择要包含或排除的目录。还指定允许的扩展名和文件大小限制。
- **7** - 打开关于窗口和设置的按钮，在其中可以自定义扫描。

## 翻译

GTK GUI 完全可翻译。至少支持 10 种语言（部分翻译是自动完成的，可能不完美）。

## 打开和操作文件

- 双击文件以在默认应用程序中打开。
- 要打开多个文件：按住 CTRL 并逐个点击文件，然后用鼠标左键双击其中一个。
- 要打开包含文件的文件夹：用鼠标右键双击它。
- 要反转组内的选择：用鼠标中键点击文件 - 它会翻转同一组中所有其他文件的选择。

## 添加目录

默认情况下，当前路径作为包含目录加载，排除目录被填入合理的默认值。

你可以通过在启动应用时传递参数来覆盖：

```
czkawka_gui /home /usr --/home/rafal --/home/zaba
```

这包括 `/home` 和 `/usr` 并排除 `/home/rafal` 和 `/home/zaba`。使用命令行参数时，"退出时保存"选项被禁用 - 目录列表不会自动保存。

相对路径和绝对路径都支持：`../home` 和 `/home` 都是有效的。

添加路径后，你可以通过右键点击将其标记为 **参考路径**。参考路径会出现在扫描结果中，但不能通过任何自动操作（选择、移动、删除）来操作。

## 常见工作流

### 查找并删除重复文件

**场景**：查找并删除 Downloads 中的重复文件，将 Documents 作为受保护的参考。

1. 打开 Czkawka GTK 并选择 **重复文件** 选项卡（面板 **2**）
2. 在目录面板（**6**）中，将 Downloads 文件夹添加到包含目录
3. 将 Documents 文件夹添加并将其标记为参考路径（右键点击 → 标记为参考路径）
4. 打开设置（**7**）并配置：
   - 检查方法：**Hash**
   - 哈希类型：**Blake3**
5. 点击 **Search**
6. 扫描完成后，使用底部面板按钮（**4**）选择重复文件
7. 点击 **Delete** 并确认

### 查找相似图像

1. 选择 **相似图像** 选项卡
2. 在面板 **6** 中添加所有照片目录
3. 在设置（**7**）中，设置：
   - 相似度阈值（越低越严格）：5-10 是一个很好的起点
   - 哈希算法：**Gradient**（推荐用于照片）
   - 哈希大小：**16x16**（平衡）
4. 点击 **Search**
5. 使用图像预览面板（**1**）在决定之前对比相似图像
6. 选择要移除的图像，然后点击 **Delete**

### 使用参考路径

1. 将你的工作目录和参考目录都添加到包含目录
2. 右键点击参考目录并选择 **标记为参考路径**
3. 参考路径中的文件会出现在扫描结果中用于比较，但绝不会被自动操作选择或删除
4. 运行扫描并正常删除 - 参考文件受到保护

## 设置

设置通过按钮 **7** 打开。主要选项：

- **检查方法** - 对于重复文件：Name、Size、Size+Name、Hash
- **哈希类型** - Blake3、XXH3、CRC32
- **最小/最大文件大小** - 过滤此范围之外的文件
- **使用缓存** - 启用/禁用哈希和缩略图缓存
- **使用预哈希缓存** - 缓存大文件的部分哈希（开头和结尾 4 KB）；加速重新扫描；必须在设置中显式启用
- **自动删除过时的缓存条目** - 每次扫描时驱逐过时的缓存条目

## 技巧和技巧

跨前端提示（缓存管理、预哈希、部分扫描、原生 CPU 构建）请参见 [主指南中的技巧、技巧和已知错误](Instruction.md#tips-tricks-and-known-bugs)。

注意：在 GTK 设置中必须显式启用预哈希缓存 - 它不默认开启（不像 Krokiet 默认启用）。

- **手动编辑目录** - 你可以直接编辑配置文件 `czkawka_gui_config.txt` 以添加、移除或更改目录。编辑后重新加载配置。
- **列可见性** - 某些列（修改日期、文件大小）可能不可见，如果其他列太宽。水平滚动结果列表或通过拖动分割线缩小其他列。

## 配置和缓存文件位置

有关默认缓存路径、环境变量覆盖和便携式驱动器设置，请参见 [主指南中的配置/缓存文件](Instruction.md#configcache-files)。

GTK 特定的配置文件：

| OS | 路径 |
|----|------|
| Linux | `~/.config/czkawka/` |
| Linux Flatpak | `~/.var/app/com.github.qarmin.czkawka/config/czkawka/` |
| macOS | `~/Library/Application Support/pl.Qarmin.Czkawka/` |
| Windows | `C:\Users\<user>\AppData\Roaming\Qarmin\Czkawka\config\` |

缓存与 Krokiet 和 CLI 共享（Linux 上为 `~/.cache/czkawka/`；Flatpak 上为 `~/.var/app/com.github.qarmin.czkawka/cache/czkawka/`）。
